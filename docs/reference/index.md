# 参考资料

本平台的教程只负责讲清「概念、路径与取舍」，**具体的 API 细节、版本差异、配置项一律以官方文档为准**。本区集中收录所有涉及技术的权威链接，方便随时跳转查证。

## 使用约定

- 教程正文出现 API、配置项、命令行参数时，优先给出官方文档链接，而不是复制粘贴官方内容。
- 涉及版本的说明统一标注最低支持版本（例如 Python 3.10+、Node.js 18+、JDK 17+）。
- 官方提供中文文档时优先给中文链接，同时保留英文原文入口（中文翻译通常滞后）。
- 链接失效或官方站点迁移时，请通过页面底部的「在 GitHub 上编辑此页」提交修正。

## 查证顺序建议

1. **官方文档** — 概念说明与推荐用法。
2. **官方 API / 规范参考** — 精确签名、参数、边界行为。
3. **变更日志 / Release Notes** — 判断某特性在你的版本里是否可用。
4. **Issue 追踪器** — 行为与文档不符时确认是否为已知缺陷。
