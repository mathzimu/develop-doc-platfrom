# 网络安全生态全景

## 安全测试工具

| 工具 | 类型 | 适用场景 |
|------|------|---------|
| **Burp Suite** | Web 安全测试 | 手动渗透测试、流量拦截与篡改 |
| **OWASP ZAP** | Web 安全扫描 | 自动化漏洞扫描、DAST |
| **Nessus** | 漏洞扫描 | 资产扫描、合规检查 |
| **Qualys** | 漏洞管理 | 云化漏洞扫描与资产发现 |
| **Nmap** | 网络扫描 | 端口扫描、服务识别 |
| **Metasploit** | 渗透测试 | 漏洞利用验证 |
| **Trivy** | 容器安全 | 镜像/仓库/SBOM 漏洞扫描 |
| **Wireshark** | 流量分析 | 网络抓包与协议分析 |

## 认证协议

| 协议 | 用途 | Token 格式 |
|------|------|-----------|
| **JWT** | 无状态认证 | JSON + 签名（JWS）或加密（JWE） |
| **OAuth 2.0** | 第三方授权 | Access Token（Bearer / JWT） |
| **SAML** | 企业 SSO | XML 断言 + 数字签名 |
| **WebAuthn** | 无密码认证 | 公钥凭证（FIDO2） |
| **OpenID Connect** | 身份认证 | OAuth 2.0 + ID Token（JWT） |

## 密钥管理

| 方案 | 托管方式 | 特点 |
|------|---------|------|
| **HashiCorp Vault** | 自托管 / HCP Cloud | 动态密钥、自动轮换、审计日志 |
| **AWS KMS** | 云托管 | 与 AWS 服务深度集成 |
| **Azure Key Vault** | 云托管 | 密钥、证书、秘密统一管理 |
| **GCP Cloud KMS** | 云托管 | HSM 支持、全球分布 |
| **SOPS** | 文件加密 | GitOps 友好的密钥加密方案 |

## 监控告警

| 方案 | 组件 | 用途 |
|------|------|------|
| **Splunk** | SIEM | 日志聚合、实时告警、安全分析 |
| **ELK Stack** | SIEM | Elasticsearch + Logstash + Kibana |
| **Snort** | IDS/IPS | 网络流量规则匹配与入侵检测 |
| **Suricata** | IDS/IPS | 高性能多线程入侵检测与防护 |
| **Wazuh** | SIEM + XDR | 开源安全监控与合规检查 |
| **Falco** | 运行时安全 | 容器和主机异常行为检测 |
