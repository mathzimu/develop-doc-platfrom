# HTML 教程

HTML（HyperText Markup Language）是构建网页的标准标记语言。所有网页的基础骨架都由 HTML 构成，浏览器将 HTML 解析并渲染为可视化的页面。

本教程从零基础开始，逐步深入到企业级应用，帮助你全面掌握 HTML。

## 环境要求

- 任意文本编辑器（VS Code 推荐）
- 现代浏览器（Chrome / Firefox / Edge）
- 无需安装额外软件

## 快速开始

创建一个 `index.html` 文件，输入以下内容：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的页面</title>
</head>
<body>
  <h1>Hello World</h1>
</body>
</html>
```

用浏览器打开该文件，即可看到第一个网页。
