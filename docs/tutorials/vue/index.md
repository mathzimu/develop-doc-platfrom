# Vue 教程

从零开始学习 Vue 3，涵盖基础语法、进阶原理、实战项目、工程实践与生态全景。

## 目录

- [Vue 基础语法](/tutorials/vue/01-basics) — 模板语法、响应式、组件、生命周期、路由、Pinia
- [Vue 进阶深入](/tutorials/vue/02-advanced) — 响应式原理、编译优化、Teleport、自定义指令、渲染函数、性能优化
- [实战项目：天气仪表盘](/tutorials/vue/03-project) — Vue 3 + Vite + Pinia + TanStack Query + Tailwind 完整实战
- [Vue 工程实践](/tutorials/vue/04-engineering) — 项目结构、API 层、权限指令、测试、CI/CD、i18n、安全
- [Vue 生态全景](/tutorials/vue/05-ecosystem) — 元框架、组件库、工具链、Nuxt 3 模板

## 前置要求

- 熟悉 HTML、CSS、JavaScript（ES6+）
- 了解 TypeScript 基础类型
- Node.js >= 18
